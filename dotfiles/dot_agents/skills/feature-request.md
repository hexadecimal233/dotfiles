## When user propose new feature for a software

When user asked:

- Could you add (a feature)
- It would be cool to add (feature)

Do the checklists:

- Never assume the meaning of words
- Take time to make sure important terms are fully understood
- Create an agreed lexicon / glossary
- Share examples wherever possible
- Never assume user's technical ability and does not guarantee technical understanding.
- Beware when they go too far into technical descriptions.
- Always try to discover what the client wants to accomplish. (Workflow/Problem)
- Focused on the target user, think twice when these ideas goes too far
